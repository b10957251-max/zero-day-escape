## 本版內容
1. 遊戲區填滿可用視窗，支援全螢幕（依瀏覽器支援），手機建議橫放。
2. 各關 2400×1800 地圖，鏡頭跟隨，方向鍵 / WASD 或四方向觸控移動；牆壁可阻擋人物，需繞行。
3. 各關 10 個探索物件，含必要提示與空值、過期資料及劇情。每次新遊戲隨機分散於四個區域，隨機種子隨進度保存。
4. 機台預設只顯示題目，集滿該關必要提示才顯示公式與完整解謎方法；仍接受玩家自行推算的正確答案。
5. 線索按鈕依關卡集中顯示必要提示、蒐集進度與解鎖後的方法；劇情紀錄另收合。空值不收入筆記。關閉後保留答題內容。
6. 取名與男女角色選擇。返回大廳、重整與重新開始保留名字與角色；新遊戲重抽地圖。
7. 放大人物、詳細物件繪製、地板與建築細節、陰影與出口開啟效果，不使用彩色互動外框。接近物件才顯示名稱。
8. 答對僅解鎖出口，走到出口互動才換關。重新開始及再挑戰一次都先回大廳。

## 存檔
本版使用 zero-day-exploration-v3 獨立格式，因地圖與物件配置更動，首次開啟 V3 會建立新遊戲，舊版存檔不刪除。
本版保存關卡、已破解狀態、名字、角色、地圖種子、道具、探索紀錄與筆記；重整後人物回當關起點。
